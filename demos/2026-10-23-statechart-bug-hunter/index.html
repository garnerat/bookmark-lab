In the browser · Maple Lane Studio

Find the bug in the statechart

Maple Lane Studio books portrait sittings. Ada can hold a slot, pay a deposit, cancel, or move the day. A card processor and the shop agent run at the same time: one captures the payment, the other confirms it, retries when a reply is missed, and sends a reminder. This page draws that chart and checks every interleaving.

The idea is from @poteto’s post: ask an agent to draw a statechart, then use a formal-verification pass in the spirit of TLA+ so you can see the user flow and the bugs a person would actually hit. This is that loop, small enough to step through on a phone.

The picture and the check

A statechart is a picture of a workflow: named states, and the events that move between them. When several parts run at once, they sit side by side. Ada, the processor, and the shop agent each have a state, and a real moment of the booking is one state from each. The shop agent is split again into a webhook and a reminder. That inner split is what the parallel box means.

The checker does, on a tiny scale, what a model checker such as TLC does for a TLA+ spec. It starts from the opening state and tries every enabled action, breadth-first, skipping a state it has already seen. That walks every ordering of the actors, including ones you would not think to demo. At each state it tests the invariants by name. The first time one fails, the path back to the start is a shortest counterexample.

With a coding agent, you would ask it to draw this kind of chart from the handlers you have — the route that books, the webhook that retries, the job that sends reminders — and then to write that chart as a TLA+ spec. You run the checker, read the counterexample as a story a customer could hit, and fix the small thing that allowed it: an idempotency key, a guard, a lock. Then you run the check again until it stays quiet. The picture is how you see the flow. The spec is how you know the fix covered the orderings, including the ones a manual test skipped.

Fictional studio, and the search stays in this tab. Ada and the print order are made up. Nothing is uploaded. There is no API key and no account. The TLA+ below is text to read. The checker that actually runs is the JavaScript in this page.
