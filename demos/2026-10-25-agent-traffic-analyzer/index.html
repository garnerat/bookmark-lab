Which agents visit your site

Paste an access log from the shop’s website. This page sorts AI assistants, training crawlers, and search engines, then shows the pages each one kept requesting.

The idea is item 2 in Greg Isenberg’s list of startup ideas: Google Analytics for agents, so you can see which agents visit your site and what they want. This is a small local version of that, for one log file.

The sample is fiction. Queen City Coil is not a real Cincinnati heating-and-cooling company, and the sample log was written for this demo. A file you choose is read on this device. Nothing is uploaded, and there is no account.

The log

Nginx and Apache call this the combined log: the time is in brackets, and the user agent is the last quoted field. A spreadsheet works too, with columns user_agent, path, and timestamp. If the user agent contains a comma, put quotes around it.

Notes on the signatures

The list is the user-agent tokens the vendors document. It is not every crawler on the web. A string that only looks similar is not given a vendor it does not have.
