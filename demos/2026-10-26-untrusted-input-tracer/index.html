Follow the input to the sink

Oakley Pipe & Air is a made-up plumbing and heating shop in Oakley, Cincinnati. This page is their booking server, a handful of short Node files, and the audit a coding agent would run on them.

The steps are the six phases in Cloudflare’s security-audit skill. The assignment is Franz Bruckhoff’s prompt of the day: trace untrusted input to sinks, check auth, dependencies, and configuration, verify what you find, and keep going after you think you are finished.

The prompt of the day

Run a full application-wide security audit strictly following the methodology in the security-audit skill.

Exhaustively trace all untrusted inputs to execution sinks, inspect all auth/access controls, dependencies, and configurations. Verify your findings. When you think you have found all vulnerabilities: You haven't. Keep investigating.

Report vulnerabilities with: (1) severity, (2) exact file/line location, (3) root cause and attack vector, and (4) concrete remediation patches.

The shop is fiction. Ada Ruiz, Ben Cho, and the two addresses were written for this demo. Nothing is uploaded. Each fixture compares dummy rows or strings in this tab. It does not start Node, a shell, or a database, and it does not call a live site.
