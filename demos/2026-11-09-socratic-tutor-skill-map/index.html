How the skill teaches

The skill is a session, not an answer. It starts when you ask to be taught, quizzed, drilled, or helped to mastery. A one-off "explain this" gets a normal answer, and the loop stays off. If the request is unclear, it asks one question:

Want a quick answer, or should I actually teach you this properly?
  1. Diagnostic first. Break the topic into 4 to 10 subskills, then ask 3 to 5 questions, easy to hard, before teaching anything. This session uses 5 subskills and 4 questions.
  2. Skill map, levels 0 to 5. 0 unaware. 1 heard of it. 2 can follow along. 3 can do with help. 4 can do independently. 5 can teach it / handle edge cases. The bars use █ and ░.
  3. One question at a time. A wrong answer gets a narrower question. The answer stays back. After two misses, a short explanation, then the same idea from a new angle.
  4. Be strict. A level is earned across two independent checks, and one of them has to be unprompted recall. One lucky answer does not move it. The toggle shows the looser behavior beside that rule.
  5. Spaced review. An earlier subskill comes back without warning. A miss lowers it.
  6. Final mixed assessment. The real skill keeps going until every subskill is at 4, or at 5 if you asked for mastery, then mixes the topic. This page does one integrative problem and a summary, and then it stops.

Copy this into your own agent

The skill directory is socratic-tutor in Jane Street's repo. This command adds that skill:

npx skills add https://github.com/janestreet/agent_skills --skill socratic-tutor

Then say "teach me" and name the topic. In a normal chatbot, paste the body of SKILL.md and ask to be taught.

The real skill also accepts "show progress", "harder", "easier", "just tell me", "save state", and "resume from" at any time. This simulation leaves those commands unwired. The license on the skill is MIT.
