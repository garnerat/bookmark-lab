Maple Street Dental is a made-up neighborhood office. Empty chairs are the problem, so the desk wants a second text for the visits most likely to be missed. An agent tries one tweak per round. A check it does not control decides whether the tweak stays.

The loop, in one night

In autoresearch, the agent may edit one file, train.py. It trains for a fixed 5 minutes. prepare.py, which the agent does not edit, prints val_bpb. Lower is better. A better score stays. An equal or worse score is thrown away with git reset. The person edits program.md, then can leave. Five minutes is about 12 experiments an hour, and about 100 over a night of sleep.

This page runs that shape on a no-show rule. The metric here is higher-is-better, because a saved chair is the thing the desk counts. The budget slider is the same idea as the fixed 5 minutes: the agent does not get a longer run just because a tweak is slow.

Three piles, split before the loop

Each pile has 260 made-up visits. The agent may read one pile. The locked check scores a different pile. Next month is a third pile, and it is not in either check. The miss rates on this seed are about 42%, 42%, and 40%.

      You can rehearse the loop on a small script before you point an agent at a real training run. Write the check, prove a bad rule fails it, then let the agent edit one file. The block below is an illustrative template written for this demo. It is not copied from the autoresearch repo.

      # program.md
# Illustrative template for this demo.
# Not copied from karpathy/autoresearch.

You may edit only no-show.js.
That file is the rule for who gets a second text.

You may not edit check.js. The check is locked.
Run it with:

    node check.js

The metric is desk_score, printed by check.js.
Higher is better.
It counts chairs saved per 100 visits on a locked pile.
A false double-confirm costs half a saved chair.
Flagging every visit must score worse than the starting rule.
If it does not, stop and fix the check before any experiment.

After each run:
- If desk_score is strictly higher than the best kept score, keep the commit.
- Otherwise run git reset --hard back to the last keep.
- A tie is a discard.

Each experiment stops at 5 minutes.
Do not lengthen the budget to make a run look better.
Do not stop the loop to ask whether to continue.

The first thing you do is write the check, and make sure it can fail.

      An hour is enough to write check.js, run the flag-every-slot rule by hand, and watch one keep and one discard. The overnight budget on this page is the part you leave running after that.
