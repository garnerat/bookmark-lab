Check your agent's code: CRAP, DRY, and mutation tests

Paste a small JavaScript module an agent wrote, plus a few tests. This page scores each function for change risk, flags blocks that are the same shape, and rewrites the code in small ways to see which edits the tests still accept.

The routine is from Uncle Bob Martin’s post. He talks a system over with his agents, they write a spec and build it in an hour or two, then he has them run the crapper, dryer, and mutator. Those checks find bugs, oversights, and dead code. Crapper is the CRAP score, dryer finds duplicate code, and the mutator is mutation testing. His tools are on github.com/unclebob, including crapper and dryer. This page is a small in-browser version of that idea for one snippet, not those tools.

Why this matters when agents write your code

An agent can turn a conversation into a working module in an hour or two. The tests that arrive with it often lock in the path you described and leave the other branches, the copied helper, and the off-by-one alone. A green run is then a weak guarantee.

These three checks are a fast second pass on that draft. They do not prove the code is right. They show where a green suite is not much of a guarantee.

  • Crapper. CRAP = complexity² × (1 − coverage)³ + complexity. Complexity is the cyclomatic complexity of one function. Coverage is the fraction of that function the tests actually run. A score of 30 or more is the usual line for a function that is complex and under-tested.
  • Dryer. Names and literals are stripped out, then sliding token windows look for blocks with the same shape. Those are the copies that will drift apart.
  • Mutator. Flip a comparison, swap + and -, nudge a boundary constant, negate a condition, or return early. Each mutant is run against the same tests. A survivor is a change the tests cannot see.

Pasted code stays in this tab. It runs in a web worker, not on a server. The worker cannot see the page. A tight loop is stopped on a timeout. There is no account, no API key, and no upload.

Use a tests array of [name, function] pairs, or functions whose names start with test. Helpers in the sandbox: assert, assertEqual, and assertClose (within 0.001). Ctrl or Cmd plus Enter runs the checks.

    Crapper

    CRAP = complexity² × (1 − coverage)³ + complexity

    Complexity starts at 1 and adds one for each if, loop, case, catch, ?:, &&, ||, ??, and ?.. Coverage is the share of statements in the function that ran. A line in the listing is pink when nothing on it ran, and hatched when only part of it ran.

    Dryer

    A block is reported when at least four lines share the same shape after identifiers and literals are normalized. Tests are left out of the comparison.

    Mutator

    A handful of mutants, spread across the operators and across functions the tests do and do not reach. A timeout counts as killed: the suite noticed that the run did not finish. The score is killed ÷ (killed + survived).
