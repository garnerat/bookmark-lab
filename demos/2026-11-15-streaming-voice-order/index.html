Patch the ticket on the partial transcript

A turn-based flow waits until the person stops, sends the whole sentence, and paints once. The drink was named in the first few words. Streaming reads each interim hypothesis and updates a structured ticket immediately. Corrections (“actually”, “no”, “make that”, “instead”, “scratch that”) rewrite that same ticket. Why the patch has to be reversible

Speech recognizers rewrite earlier words in place. They do not only add text at the end. Naive append mode treats a rewritten hypothesis as new speech, so when “a large oat latte” becomes “I'll have a large oat latte” it adds a second latte. Re-deriving from the full partial transcript builds the ticket again from the words now in hand, and the same words always make the same order.

      What the counter can hear

      • Drinks: latte, cortado, cold brew, chai, matcha.
      • Sizes: small, medium, large. Hot or iced. Cold brew starts iced.
      • Milk: whole, oat, almond, skim, soy. Extra shot.
      • Syrups: vanilla, caramel, hazelnut.
      • Pastries: croissant, muffin, scone, banana bread.

      Why this matters for a small business

      On a drive-thru headset, at the counter, or on a phone order, the drink is named early and then corrected. If the ticket waits for silence and a model round trip, the person on the register looks at a blank screen while the line moves. If the ticket fills in as the words arrive, they can read the drink back and confirm it before anyone is charged. The correction still has to land on the same cup.

      Try it in under an hour

      You can see the shape of this in one page, in Chrome or Safari. webkitSpeechRecognition with interimResults hands you a new hypothesis while the person is still talking. Parse that whole string and replace the ticket. Do not append. Firefox has no SpeechRecognition; the text box on this page is the stand-in. The block below is an illustrative starter written for this demo. It is not Jev, and it does not call a model.

      // Illustrative starter for a counter ticket.
// Not Jev, and not a model.
// Re-derive on every interim result. Do not append.
// Interim hypotheses rewrite earlier words.

const SR = window.SpeechRecognition || window.webkitSpeechRecognition;
const hear = new SR();
hear.interimResults = true;
hear.continuous = true;
hear.lang = "en-US";

function parseTranscript(text) {
  const words = text.toLowerCase().replace(/[^a-z\s]/g, " ").split(/\s+/).filter(Boolean);
  const joined = words.join(" ");
  const drinks = ["cold brew", "latte", "cortado", "chai", "matcha"];
  const drink = drinks.find((name) => joined.indexOf(name) !== -1) || null;
  const size = ["small", "medium", "large"].find((name) => words.indexOf(name) !== -1) || null;
  const milk = ["oat", "almond", "whole", "skim", "soy"].find((name) => words.indexOf(name) !== -1) || null;
  const iced = words.indexOf("iced") !== -1 || words.indexOf("ice") !== -1;
  return { drink: drink, size: size, milk: milk, temp: drink ? (iced ? "iced" : "hot") : null };
}

function render(order) {
  let slot = document.querySelector("#ticket");
  if (!slot) {
    slot = document.createElement("p");
    slot.id = "ticket";
    document.body.appendChild(slot);
  }
  const bits = [order.size, order.temp, order.milk, order.drink].filter(Boolean);
  slot.textContent = bits.length ? bits.join(" ") : "Listening…";
}

hear.onresult = (event) => {
  let text = "";
  for (const result of event.results) text += result[0].transcript;
  render(parseTranscript(text));
};

hear.start();
