Is the agent's test suite honest?

An agent wrote a quote calculator for Linwood Comfort, a made-up heating-and-cooling shop on the east side of Cincinnati, and the AI-written tests that ship with it. Every line runs. The asserts mostly check that a number came back.

The routine is from Uncle Bob Martin’s post on ub-mode and the ub-mode repo. The checkers it names are Crapper, Dryer, and Mutator.

What ub-mode asks an agent to do

ub-mode is a short skill file for coding agents. The order is make it work, then make it right. It is a reduced skill, loosely based on poteto-mode, paired with three checker programs. This page does not copy the skill. It runs the honesty check the skill asks for after the code is written.

  1. Get the data shape right before the logic. Then write a failing test, watch it fail for the reason you expect, and make the smallest change that passes.
  2. Check the result. Crapper scores each function from cyclomatic complexity and the fraction of that function the tests run. CRAP = complexity² × (1 − coverage)³ + complexity. ub-mode wants each function under 10. Dryer flags code with the same shape at a similarity of 0.8 or above. Mutator changes one small thing and reruns the tests.
  3. An edit that still passes is a survivor. Cover lines that never ran, make the survivors fail, and delete code nothing needs.

Line coverage on this page is the share of lines a test reaches. At 100%, CRAP equals complexity, so a function can look calm while the assert only checks the type. The mutation score is the share of edits the suite rejects. That is a cheap honesty check on tests an agent wrote for its own code.

The buttons add one stronger test at a time, in the spirit of writing the failing test first. The original calculator still passes. Edits that used to survive start to fail. A clean score means these tests notice the edits below. It is not a proof the program is finished, and it is not the Crapper, Dryer, or Mutator tools themselves.

Crapper, on this file

CRAP = complexity² × (1 − coverage)³ + complexity. Each function starts at 1. An if, loop, catch, case, &&, ||, ??, ?., or ?: adds one. A line counts when a test reaches it. ub-mode wants each function under 10. These numbers are counted from the file, not filled in by hand.

One-character edits
