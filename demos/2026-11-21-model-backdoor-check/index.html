    What catches it

    Each switch is part of the toy. The badge says what that switch does to the download and the day you have selected.

    Try it in under an hour

    For a small shop running a local model. The check itself is a few commands once a quantizer is already installed.

    1. Download the weights from the original publisher, the lab or company that released the model. Use their release. Skip a re-upload, and skip a file someone else already quantized.
    2. Check the SHA-256 before you load the file. On a Mac:

      shasum -a 256 <file>

      On Linux the same check is sha256sum <file>. Compare the hash to the checksum the publisher posted for that exact file. If it differs, delete the download.
    3. If you need a smaller file, quantize that checked download yourself. llama.cpp's tool is llama-quantize. Some builds still name it quantize. On a Mac, MLX's tool is mlx_lm.convert. Read --help in the version you installed. The input is the publisher file you just checked.
    4. Keep an allowlist for the shell commands the agent may run. A nightly copy of the estimates folder can be on the list. Anything else waits for a person. Leave a download piped into a shell off the list.
